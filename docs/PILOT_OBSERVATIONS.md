# 试测统计与报告反馈（V12）

## 已实现

- 单次测评使用随机编号。草稿保存该次记录，恢复后续记，账号切换重置内存记录。
- 记录完成状态、最后停留页、已答题量、逐页估计耗时、年级与学生类型。不记录题目原文或选项值。
- 隐藏页面与返回资料页期间暂停计时；每次可见交互间隔最多计60秒。页面含多个模块时，按各模块题量分摊时间，因此模块耗时仅为估计值。
- 每次观察以同一编号更新快照，未完成不等同于主动退出，也不证明退出原因。
- 报告末尾提供折叠反馈表单；符合程度、类别与可选意见关联报告编号。再次提交更新同份报告的反馈。
- 网络失败时保留最多50条待同步记录，网络恢复或再次打开测评页后重试；浏览器存储失败时明确提示。
- 家长报告页脚显示版本与生成日期。静态独立导出保留页脚、移除依赖在线服务的反馈表单，打印同样隐藏表单。

## 接口与后台

复用现有 POST /api/reports，增加 recordType=assessment_session 或 assessment_feedback，与正式报告使用不同编号。现有 Node / Worker 接口均保存完整JSON，无需新增数据库字段。后台加载最近最多200条混合记录，正式报告列表排除两类试测记录，另设“试测与报告反馈”面板。统计受加载范围与日期筛选影响，不展示为全站总量；原接口保留数量限制仍适用。

测试：node scripts/test_study.js，含独立临时 Node 接口的写入与管理端读取验证。另运行原有答题、恢复与稳定性回归。未向生产后台发送模拟试测记录。

## 后续需要真实学生参与

邀请不同年级学生试测，记录题意理解与意见；安排间隔复测；依据实际耗时与反馈决定精简题目。当前实现为收集依据，不代表已完成真实学生试测、权重校准或效度验证。
