# 双功能账号升级 V18

## 使用规则

- 发放时可选仅测评、仅高考查询或两项，分别设置1—365天有效期。
- 专业测评提交一次后核销，原报告可查看7天；高考查询在有效期内可重复使用，不随测评核销。
- 旧账号保持仅测评权限，管理员可编辑开通查询；已有报告、密码保留。
- 后台支持姓名、账号、年级、备注搜索和权限筛选。查询记录通过服务端身份关联。
- 重置测评与密码会撤销旧会话并允许重新测评，不延长或清空高考查询期限和历史。
- 高考参考数据仍随静态页面公开提供；账号控制使用入口和记录接口，不对静态数据加密。
- JSON存储沿用单进程PM2部署，勿启动多个写入实例。

## 部署顺序

先更新阿里云API，确认 `/api/auth/capabilities` 返回 `version:2`、`dualAccess:true`，再发布V18前端。

本次只替换 server.js 和 access.js，不复制.env、数据目录，不运行管理员初始化脚本。
管理员密码、现有报告及账号账本保留。升级前备份整个 `/var/www/majornavi-report-api`。
现有PM2环境已保存管理员配置，运行 `pm2 restart majornavi-report-api`，随后 `pm2 save`。
回滚时恢复备份代码并重启同一进程，不覆盖升级后新增的数据。

## 验证

`node scripts/test_dual_access.js` 验证独立权限、期限、核销、报告窗口、旧账号兼容、撤销、查询幂等及记录归属。
原有账号、测评流程、报告生成和报告恢复回归测试均通过。
本地浏览器已验证双功能账号发放、学生功能菜单、高考查询及后台查询次数更新。
