# 账号管理 V19

前端升级，无需更新阿里云API或管理员配置。

- 概况显示全部账号、可继续测评、已有报告、查询未使用和7天内到期的账号数。
- 到期按测评截止、已完成报告查看截止、高考查询截止分别计算；一个账号只计一次。停用账号不计入到期提醒。
- 到期筛选可能包含仍有其他可用功能的账号；已完成测评使用报告窗口，不把原测评截止日期当成待续期权限。
- 待办筛选与搜索、状态、开通功能交叉使用。导出清单只包含当前筛选结果，不含密码。
- 发放区可复制单个使用者的登录信息；整批CSV依然只在生成或重置当次提供密码。
- 提醒在加载或刷新账号列表时更新，不向学生自动发送消息。

验证：`node scripts/test_account_insights.js` 覆盖独立期限、报告窗口、停用排除、7天边界、统计和CSV转义。本地浏览器已验证批量生成、单人复制、提醒、筛选及刷新。
