# 推荐区分度与提交前核对 V23

## 专业区分度

固定广泛兴趣、信心及其他作答，仅改变专业任务偏好，分别检查数学、物理、计算机、化学、生物方向。五组预期方向均可区分；同输入重复结果一致，未知任务保持中性。既有单题扰动稳定性检查通过。
本轮没有修改推荐权重：当前回归未发现必须通过调整权重修复的问题。新增测试作为后续更改的回归约束。工程、经营等领域仍结合其他兴趣和技能，不能承诺单项任务偏好决定首选。

## 作答核对

- 漏答仍定位到未答页，必须补答；“尚不了解”是有效回答，不视为漏答或低兴趣。
- 当某类领域至少一半没有有效任务评价、同维不同任务评分差异至少0.75，或有计时数据且至少20题平均有效记录时间不足2秒时，显示提交前核对。
- 这些是自建核对规则，不是“无效作答”判据，不生成准确率或可信度分数，不因连续相同选项判定异常。
- 可返回相关题目修改，也可保留真实回答并确认生成；确认前不提交报告、不核销测评次数。修改答案后重新核对。
- 保存内部核对标记；家长报告只在信息不足时增加一句范围说明，不展示逐题记录、计时标签或内部规则。历史报告不补造核对结果。
- 学生报告、后台预览和PDF保留相同的信息不足说明。
