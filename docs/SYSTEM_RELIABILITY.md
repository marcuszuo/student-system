# 测评流程可靠性优化

2026-10-18，本次不调整测评分数、专业排序和家长报告结构。

- 草稿按当前登录账号保存，恢复时保留题目顺序、答案和页码；开始评估不再重新抽题。
- 默认 student 账号兼容旧版未分账号草稿，其他账号不会自动读取该草稿。
- 无效答案不计入完成进度；浏览器存储失败时保留本次内存中的作答并提示用户。
- 相同作答及学生资料重复提交时复用原报告；修改后允许重新生成。
- 报告上传设 15 秒超时，失败支持重试，网络恢复后自动尝试同步。
- 上传按账号和报告编号防重；旧请求完成时不会覆盖更新的报告记录。
- 本地缓存失败时，仍尝试上传当前内存中的报告。

验证脚本：test_system_flow.js、test_assessment_report.js、test_report_recovery.js、check_recommendation_stability.js。账号隔离是浏览器草稿隔离，不改变现有服务端身份验证机制。
