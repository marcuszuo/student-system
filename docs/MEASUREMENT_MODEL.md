# 独立测量模型（2026-10-17）

新增30道MajorNavi自建题：六类活动兴趣12题、技能信心8题、工作价值观6题、实践经历4题。仅将Holland六类兴趣作为分类参照，没有使用MBTI或Kuder正式题目、常模和评分，也不继承这些工具的信效度。

每个兴趣、信心和价值维度分别评价，1—5级转换为0—1后按该维度取均值，不再因选择其他领域而降低本维度。信心题允许选择U（缺少经历），不纳入均值，也不作为零信心参与专业距离。经历题单独记录自述经历，不合并进技能信心分。

自建专业比较规则：兴趣权重1，技能信心0.7，价值观0.45，数理/统计学科准备0.35。学习性格、认知方式与抗压维度不直接决定专业排序。成绩辅助调整不会改写独立测得的兴趣、技能信心和价值观。自述实践信息用于解释推荐证据，不冒充客观能力验证。

完整模式核心120题，追加校准18题，必要时再追加4题；标准模式保留六类兴趣和四类技能的覆盖。所有追加题排除已出题ID。历史报告缺少新增模块时显示未包含独立测量信息，不伪造补测结果。

报告继续遵循：测评结论 → 学生特征 → 专业推荐比较 → 后续建议。独立测量结果与“喜欢但信心不足”“信心较强但经历有限”等综合解读放在学生特征部分；学习协作偏好辅助展开；具体数值、作答记录和方法说明放在附录。

以上题目、维度与权重为产品规则，尚需真实学生样本进行题目理解、稳定性、信效度和公平性检验，不能将软件回归测试视为心理测量验证。

验证：`node scripts/test_assessment_report.js --export`、`node scripts/test_report_recovery.js`。独立报告打包：`python3 scripts/export_g11_report.py`。

## 2026-10-18：专业任务分流与固定作答检查

新增9个领域各2道任务偏好题（共18道），包含编程、电子、机械、数学、化学、生物、经营组织、人与公共服务、设计表达。均为自建情境题；可以选择暂时无法判断，该选项不按低意愿计分。减少18道原有情境核心题，完整核心总量仍为120，最多142道；标准核心80道，九个领域均覆盖。

领域偏好独立于Holland六类兴趣，不回写兴趣和信心分数。对显式映射的候选专业，专业距离增加 `0.3*(0.5-领域偏好均值)`，范围为-0.15至0.15。未映射或没有有效回答时调整为0，保持中性，不据此排除专业。映射与系数属于可审查的产品规则，不代表实证效度。报告逐项说明任务偏好是否支持推荐。

`node scripts/check_recommendation_stability.js` 使用版本化固定题目ID和四组合成作答，比较有无领域信息的同一输入，并逐次扰动一道回答。输出位于 `exports/stability-20261018/`。该结果用于软件敏感性回归，不替代真实学生的复测和效度研究。重建基准需要显式运行 `--freeze`，普通测试不会覆盖固定作答。

## 家长版报告呈现（v10）

家长报告只包含测评结论、五维学生画像（兴趣方向、思考与学习方式、实践倾向、表达与协作、职业价值取向）、专业比较与简短后续建议。移除体系介绍、评分规则、数值列表、逐题复述及技术附录。内部结构化测量数据仍供评分与回归验证使用，不在家长报告呈现。

独立报告由 `scripts/export_parent_report.js` 直接渲染静态正文，附带样式与打印按钮，不打包完整题库、原始作答或评分源代码。`scripts/export_g11_report.py` 为兼容入口。测试检查家长正文不含题目明细和内部技术词，并保留固定作答稳定性回归。
